# 从塔勒布的动态对冲视角审查 ThetaTree 期权模型

在欧式行权、同一标的各期权共用 IV、零股息及零交易成本的页面设定下，定价、常用 Greeks、合约乘数和正股 Delta 对冲方向均通过了本次抽样核对。模型能估算当前敞口和给定情景下的损益。用它评价多次调仓后的策略收益时，需要考虑两项限制：两次调仓之间仍有价格和波动率风险，账簿也未计入融资和执行成本。另有一处零波动率边界问题，详见下文。[模型与记账源码](../legacy.html)

## 默认 TQQQ 组合的对冲实验

以模拟股价 60 美元、剩余 30 个自然日、年化 IV 65%、年化无风险利率 4% 建仓。组合买入 1 张行权价 60 美元的 Put，卖出 2 张行权价 55 美元的 Put，每张代表 100 股。组合初始 Delta 为 +10.756 股，卖空 11 股后剩余 −0.244 股。成交价等于当时的模型估值，所以对冲动作本身没有产生利润或亏损。

下表各行都从同一笔初始对冲出发，独立改变情景参数，再对所有持仓重新估值。金额为整个组合的美元损益。

| 对冲后的情景 | 组合损益（美元） |
| --- | ---: |
| 成交瞬间，所有参数不变 | 0.00 |
| 股价从 60 跌至 54，期限和 IV 不变 | −55.05 |
| 股价从 60 涨至 66，期限和 IV 不变 | −35.74 |
| 股价跌至 54，剩余期限减至 29 天，IV 从 65% 升至 80% | −145.87 |

卖空正股抵消了大部分一阶价格敞口，但组合的起始 Gamma 仍为 −2.493 股/美元。股价每变化一美元，所需的对冲股数也会随之改变。本例中，股价上下跳动 10% 都产生亏损，而且亏损金额不同。初始 Vega 为 −4.79 美元/波动率百分点，因此最后一行还叠加了 IV 上升的影响。这些数值来自完整重新定价；初始 Gamma 和 Vega 只能描述起点附近的敏感度。塔勒布对离散对冲的讨论解释了为什么调仓间隔内的价格变动和 Gamma 变化会产生复制误差。[塔勒布《Three Problems with Dynamic Hedging in Discrete Time》](https://www.fooledbyrandomness.com/dynamic.pdf)

## 定价、Greeks 和交易记账

直接调用网页中的定价引擎，在行权价 100、连续股息率 1% 下，组合股价（80、100、120）、剩余天数（1、30、60）、IV（15%、65%、100%）、利率（−5%、4%）和期权类型（Call、Put），共检查 108 组参数。这里使用非零股息率是为了检验引擎的通用公式，页面模拟仍取零股息。

| 检查项 | 方法 | 最大绝对误差 |
| --- | --- | ---: |
| Delta | 对现价做中心差分，每侧变动 0.001 美元 | 2.41 × 10⁻⁹ |
| Gamma | 对现价做二阶中心差分，每侧变动 0.001 美元 | 8.07 × 10⁻⁸ |
| Theta | 对剩余年数做中心差分，取负后除以 365 | 5.75 × 10⁻¹⁰ |
| Vega | 对小数形式的年化 IV 做中心差分，再除以 100 | 9.58 × 10⁻¹¹ |
| 看涨看跌平价 | 核对 C − P = S exp(−qT) − K exp(−rT) | 1.43 × 10⁻¹⁴ |

误差按各项输出单位列示并向上取整。Theta 的差分步长为 10⁻⁷ 年，Vega 的差分步长为 10⁻⁵。另以股价和行权价均为 100、期限一年、IV 20%、利率 5%、零股息为基准，Call 与 Put 的价格分别为 10.450584 和 5.573526 美元/股。[Black–Scholes 定价、Greeks 与自融资复制推导](https://www.columbia.edu/~mh2078/FoundationsFE/BlackScholes.pdf)

组合按带方向的持仓数量汇总 Greeks，正股乘数为 1，期权乘数为 100。在上述股价 54、剩余 29 天、IV 80% 的压力情景下，按当前模型价格平掉两张行权价 55 的空头 Put，同时卖出两张行权价 50 的同期限 Put。调仓前后的总损益差为 0.00 美元，旧腿亏损转入已实现损益，新腿以当时的成交价入账。

## 已确认的零波动率边界问题

当 S = K = 100、r = q = 0、剩余期限一年且 σ = 0 时，Call 和 Put 的价格均为零，代码也对二者返回 Delta = 0、Vega = 0。此时价格关于现价存在折点，Delta 没有唯一导数。若采用正波动率趋近于零的约定，Call 和 Put 的 Delta 应分别趋近 +0.5 和 −0.5。两者价格关于波动率的右导数按每个波动率百分点折算均约为 0.3989 美元/股。当前界面最低 IV 为 15%，直接调用引擎时才会遇到这一零波动率分支。

## 动态对冲的损益口径

当前账簿累计已实现损益和未平仓头寸的价差。无风险利率进入期权定价公式，但买股、卖空和收付权利金产生的现金余额没有独立计息。成交也未计入买卖价差、滑点和手续费。因此，实验结果衡量的是给定路径下未计融资和执行成本的模拟损益。

若要比较每日调仓与价格触发调仓，应让两条规则使用相同的初始资本、价格路径和 IV 路径。每次成交更新正股和现金头寸，在调仓间隔内计息，扣除成交成本，并在同一终点评价净资产、剩余风险与复制误差。这样才能将调仓频率的效果与行情路径本身的影响区分开来。[自融资对冲的现金账户定义](https://www.columbia.edu/~mh2078/FoundationsFE/BlackScholes.pdf)
