# ThetaTree

**Harvest Theta. Own Convexity. Survive Uncertainty.**

ThetaTree 是浏览器本地运行的期权组合管理终端。首页面向持有股票、卖出权利金和买入尾部保护的账户。持仓、估值参数、提醒与交易记录保存在 IndexedDB 中。Chart.js 随项目提供，首次加载新终端也可以在断开外网时完成。

## 运行

在项目根目录启动含行情接口的本地服务器，然后打开 [本地终端](http://127.0.0.1:8080/)。

```sh
python3 server.py --port 8080
```

应用使用原生 ES 模块，无需安装 npm 包。仅使用组合分析时也可运行 `python3 -m http.server 8080 --bind 127.0.0.1`。保持浏览器、主机名和端口一致即可恢复本地账户。在 Settings 中导出 JSON 可以备份或迁移到另一浏览器。多标签页使用 IndexedDB 事务和修订号检测写入冲突，发生冲突时重新加载后再编辑。

旧版比率价差终端保留在 `legacy.html`。需要旧版 SQLite 和行情接口时，运行 `python3 server.py` 并打开 `http://127.0.0.1:8000/legacy.html`。新版账户独立于旧数据库。详见[旧版操作手册](docs/legacy-terminal.md)。

## 用演示账户验算

初始快照固定在 2026-11-25，TQQQ 参考价为 $42。600 股股票的每股成本为 $65，另持有 6 张一年后到期、行权价 $30 的 Long Put，每张 100 股，入场价和手动估值均为每股 $2。示例补充假设为现金 $0、手续费 $0、IV 55%、无风险利率 4%、股息率 0、年度保险预算 $2,000。这些都是模拟输入。

打开 Dashboard 可核对净资产 $26,400、未实现盈亏 −$13,800。打开 Payoff Analyzer，保留原始成本基准与最终到期日，点击 3、6、12 张 Put。情景调整只用于分析。若要修改账户中的真实数量，在 Portfolio 编辑持仓。

| Put 张数 | 股票名义覆盖 | 到期时标的 $30 的盈亏 | 到期时标的 $0 的盈亏 | $30 以下的收益斜率 |
| ---: | ---: | ---: | ---: | ---: |
| 3 | 50% | −$21,600 | −$30,600 | +300 股 |
| 6 | 100% | −$22,200 | −$22,200 | 0 股 |
| 12 | 200% | −$23,400 | −$5,400 | −600 股 |

12 张组合在 $30 以下每再跌 $1，组合盈亏改善 $600；在 $0 处，组合相对原始成本仍亏损 $5,400。6 张组合的到期最大损失为 $22,200，向上盈亏平衡点为 $67。

## 工作流

- **Portfolio** 录入 Stock、Put、Call，多空方向与正数量分开输入，内部以带符号数量表示。Covered Call、Cash Secured Put、价差和 Collar 通过逐腿录入构成，同标的头寸在分析中共同估值。期初快照保留手动现金余额，新增交易则同步记录现金流。编辑既有开仓记录会修正对应流水。平仓前确认估值，平仓后可在日志核对现金流和利润。
- **Dashboard** 汇总多标的账户和五项 Greeks，图表按选定标的显示。账户还展示周、月期权净现金流、年度保险支出和 ±10% 同步价格冲击。跨年持仓缺少年初估值时，年度收益显示缺少数据。
- **Payoff Analyzer** 按标的展示组合、股票以及已录入期权策略的子曲线。可设标的价格、行权价、Put 数量及入场权利金、IV 平移、分析天数和成本基准。价格 × IV 热力图使用相同估值函数。
- **Roll Analyzer** 比较现有合约和候选行权价、到期日、权利金，展示净收付、旧腿已实现盈亏、Greeks 差异及移仓前后曲线。该工具只分析候选方案。
- **Antifragility Lab** 计算价格冲击、测试区间内最大损失、低价区间斜率、名义和 Delta 调整保护。TQQQ 可输入逐日指数收益序列、费用或载入预设路径。累计因子逐日乘以 `max(0, 1 + 3 × 当日指数收益率 − 年费率 / 252)`。实际基金还存在跟踪误差和融资等因素。参见 [ProShares 对 TQQQ 每日目标的说明](https://www.proshares.com/our-etfs/leveraged-and-inverse/tqqq)。
- **Insurance Manager** 跟踪本年购入保护 Put 的成本、平仓回款和剩余预算，可按相同行权价对比无保险、部分、全额和超额保护。
- **Risk Monitor** 支持保险续期、Put 盈利兑现、Delta、卖方权利金收益、指派现金及超卖覆盖等提醒。开仓参考价和开仓 IV 可选填，填入后启用相对变化提醒。Settings 中可修改阈值。
- **Trade Journal** 区分 Open / Close 事件、带方向的成交现金流和已实现收益，按周、月、季、年筛选，支持完整流水 CSV 导出。Settings 支持整个账户 JSON 导入导出，导入先校验，再由用户确认替换。
- **模拟沙盘** 沿用旧版期权模拟工作区，可创建标的、切换 1:−2 和 W 型预设、叠加保护腿、模拟 Roll Down 或正股 Delta 对冲。拖动现价、IV、期限可对比当日和到期曲线，同时更新单腿计算器。操作仅修改所选模拟标的，最近 40 次持仓操作可在本次页面会话中撤销。模拟持仓和最近 60 条记录与旧版共用 SQLite；纯静态服务沿用原浏览器模拟存档。
- **市场观察** 可切换股票指数、大宗商品、外汇和波动率，查看 11 项指标。自选股支持六个交易所和日内至全部历史区间，与旧版共用 SQLite 列表及当前选择。报价带来源和时间；数据源故障时提示异常并重试。
- **Settings** 设置估值日、快照现金、利率、预算与风控参数。顶部按钮切换明暗主题。

## 估值与记账约定

1. 股票乘数为 1，期权乘数默认为 100。开仓佣金为整笔费用。未实现盈亏等于 `(估值 − 入场价) × 有符号数量 × 乘数 − 开仓佣金`。平仓将该利润从持仓转至流水，平仓现金流按成交价值记账。现金余额应输入扣除已有期初持仓支出后的余额。
2. 定价使用欧式 Black–Scholes–Merton 近似、连续股息率和 ACT/365。支持市场价反推 IV。手动 Greeks 是**每股、买入一份该期权**的 Greeks，Put Delta 自带负号。Theta 按自然日，Vega 和 Rho 按一个百分点。程序仅在聚合时乘以带方向数量与乘数。模型推导可参考 [Martin Haugh 的 Black–Scholes 讲义](https://martin-haugh.github.io/files/FoundationsFE/BlackScholes.pdf)。
3. 持仓表优先使用未到期合约的手动市场价。理论曲线逐腿使用模型价。以当前市值为基准时，即使在估值日和原参考价处，手动市价与模型价之间的差异也会体现在曲线上。
4. 分析日已到期的腿按情景标的价现金结算，之后现金不计息；尚未到期的腿保留剩余期限。此为指定的路径假设。单一到期日的极值按所有行权价、零价格和最右端斜率求解，无上界时显示 Unlimited。跨到期日仅报告情景结果。
5. Risk Monitor 的名义覆盖按每个标的分别匹配股票并封顶 100%；实验室另外展示可超过 100% 的 Long Put 名义比例。指派资金按全部 Short Put 同时指派计算。流动性状态只反映现金覆盖，未接入成交深度、买卖价差和券商保证金。
6. 压力测试采用离散情景。尾部标签比较参考价 1% 至 10% 区间和 90% 至 110% 区间的收益斜率，不构成全域凸性证明。模拟不自动执行交易。快照估值日由用户维护；过期持仓若未手动结清，暂以当前标的参考价计算内在价值，真实结算需按成交记录核实。

## 代码与扩展

| 路径 | 职责 |
| --- | --- |
| `index.html`, `css/` | 终端布局、响应式导航与主题 |
| `js/app.js`, `js/ui/` | 页面路由、表单、图表、导入导出及事务提交 |
| `js/core/pricing.js` | BSM、边界处理、IV 二分反推 |
| `js/core/portfolio.js`, `greeks.js`, `payoff.js`, `risk.js` | 持仓方向、账户估值、收益函数、风险聚合 |
| `js/core/storage.js` | 版本化快照校验与 IndexedDB 事务 |
| `js/strategy/`, `js/alerts/` | Wheel、移仓、保险、尾部分析及可配置提醒 |
| `data/demo.json`, `tests/` | 可导入初始账户、计算与回归测试 |
| `js/vendor/` | Chart.js 4.4.8 及其 MIT 许可证 |

扩展定价器时可在 `model(position, book, spot, date, iv)` 中接入美式二叉树，保持每股价格及五项 Greeks 的单位一致。行情适配器可以更新 `quotes[symbol]`、期权 `market` 与 `greeks`。交易文件适配器应先生成候选账户，再复用 `validate` 和版本化事务保存。

本次交付以第一阶段八项功能为验收范围。第二阶段已有移仓比较、保险统计、Open / Close 日志和基础路径模拟。自动指派与行权生命周期、分层保险优化、基于账户净值历史的回撤与 Expected Shortfall、CSV 成交导入、IBKR 连接、美式提前行权定价仍待实现。

## 测试

浏览器运行应用无需 Node.js。开发环境可用 Node.js 22 运行纯函数测试，用 Python 运行旧服务的接口测试。

```sh
node --experimental-default-type=module tests/core.test.mjs
python3 -m unittest discover -s tests -v
```

测试覆盖标准价格与 put–call parity、五项 Greeks 的数值差分、IV 反推、零波动和极端价格、合约方向和乘数、跨期限估值、现金与收益守恒、保险预算、提醒阈值、JSON 校验、3/6/12 张保护的尾部形状及每日杠杆重置。
