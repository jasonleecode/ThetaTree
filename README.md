# ThetaTree

**期权 1:−2 比率价差动态移仓与 W 型策略模拟终端。**

ThetaTree 是一个单文件 HTML 应用，用于观察期权组合在不同价格、隐含波动率和剩余期限下的损益与风险变化。定价、Greeks、持仓编辑、曲线绘制和模拟交易均在浏览器中运行，无需安装依赖或配置后端。

界面采用暗色终端风格，支持桌面和移动端布局，内置 `SPCX / SpaceX`、`TQQQ`，并支持自行新增标的。所有初始价格均为假设值，不表示实时行情；`SPCX / SpaceX` 是模拟标识。应用不连接券商，不执行实盘交易。

## 快速开始

下载或克隆仓库后，直接用浏览器打开 [index.html](index.html)。私有仓库需要相应访问权限；已登录 GitHub CLI 时可执行：

```bash
gh repo clone jasonleecode/ThetaTree
cd ThetaTree
```

也可以用 Python 3 启动本地静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

随后访问 <http://127.0.0.1:8000>。

浏览器需要启用 JavaScript，并能访问 `cdn.tailwindcss.com` 和 `cdn.jsdelivr.net`。依赖通过 CDN 加载，因此单文件不等于完全离线可用。无需 `npm install` 或构建命令。

## 功能

- **多标的工作区**：切换 SPCX、TQQQ 或自建标的，各自独立保存持仓、情景、计算器参数与交易记录；标的和持仓自动保存在当前浏览器。
- **Black–Scholes 定价**：纯 JavaScript 实现欧式 Call / Put 价格、标准正态分布近似及 Delta、Gamma、Theta、Vega。
- **实时情景沙盘**：调整现价、IV 和剩余天数，同步更新估值、组合 Greeks、图表和策略信号。
- **持仓构建器**：添加、修改或平仓 Put、Call、正股；支持数量、行权价与入场成本编辑。
- **收益结构分析**：叠加到期损益与当日理论损益，在整个 `S ≥ 0` 价格域求解到期盈亏平衡点及最大盈利、最大亏损。
- **动态移仓助手**：追买保护 Put、同到期日 Roll Down、正股 Delta 对冲；执行后直接修改模拟持仓。
- **交易记账与撤销**：平仓收益计入已实现盈亏，保留最近 60 条操作记录，支持撤销最近 40 次持仓操作。
- **单腿计算器**：与沙盘共享现价、IV、期限和利率，可独立选择期权类型与行权价。

## 标的管理

通过页面顶部的“当前标的”下拉框切换工作区。每个标的独立记账；切换不会平仓，也不会将不同标的的持仓或盈亏混合。当前版本不计算跨标的组合风险。

首次打开默认选择 **TQQQ**。如果浏览器已保存有效的标的选择，则恢复上次选择；没有可恢复的选择时使用 TQQQ。

| 内置标的 | 模拟初始价格 | 初始 IV / 期限 | 默认 Put 行权价（买入 / 卖出） | 保护 Put / 右侧 Call | 现价滑块范围 |
| --- | ---: | --- | --- | --- | --- |
| SPCX / SpaceX | $135 | 65% / 30 天 | $135 / $125 | $115 / $135 | $90–$170 |
| TQQQ | $60 | 65% / 30 天 | $60 / $55 | $50 / $60 | $35–$85 |

**TQQQ 的 $60 是演示用假设价格，不是最新报价。** 两个内置标的均使用年化利率 4%、股息率 0 和每张期权 100 股的模拟约定。

### 新增自己的标的

1. 点击“＋ 新增标的”。
2. 填写标的代码、可选名称、模拟初始价格、初始 IV 和行权价间距。
3. 点击“创建并切换”，自动建立该标的的 1:−2 Put 比率价差。

代码会去掉首尾空白并转为大写，不允许重复；支持 1–20 位字母、数字、点、横线或下划线，首位必须为字母或数字。初始价格范围为 $1–$10,000，IV 为 15%–100%；价格与间距最多两位小数，间距至少 $0.01，且必须保证保护腿行权价不低于 $0.01。最多保存 50 个标的。

若初始价格为 `K`、间距为 `d`：

- 默认组合买入 1 张 `K Put`，卖出 2 张 `(K − d) Put`。
- 保护腿买入 2 张 `(K − 2d) Put`，W 右翼买入 1 张 `K Call`。
- 现价滑块范围自动设为初始价格的 65%–135%，保留两位小数；初始期限为 30 天。
- 追买保护腿时使用当前最高 Put 空头行权价减去 `d`；Roll Down 使用约 `d / 2` 的间距，按美分取整且至少为 $0.01。

例如新增 `TEST`，初始价格 $10、间距 $1，会得到 `$10 / $9` 的默认 Put 组合、`$8` 的保护腿和 `$10` 的 Call 右翼。新建后可通过沙盘与持仓表调整情景和实际持仓；“重置参数”和策略预设仍使用创建时的初始配置。

### 保存与恢复

标的列表、当前选择、各标的持仓、已实现盈亏、情景、单腿计算器和最近交易记录会自动写入当前浏览器的 `localStorage`。刷新后恢复；撤销记录仅在当前页面会话中保留，切换标的不会丢失，刷新后清空。

保存仅限当前浏览器与访问地址，不同步到 GitHub、服务器或其他设备。更换端口、域名或浏览器可能看到独立的数据；直接使用 `file://` 打开时，本地存储行为取决于浏览器，建议固定使用上述本地 HTTP 地址。清理网站数据会移除保存内容。存储被禁用、空间不足或保存内容损坏时，页面会显示提示；仍可在当前会话中模拟。

## 预设策略

### 默认：1:−2 看跌比率价差

以下以 SPCX 为例。TQQQ 和自建标的使用各自的初始价格与行权价间距。

| 参数 | 初始值 |
| --- | --- |
| 模拟标的 | SPCX / SpaceX |
| 现价 | $135 |
| 隐含波动率 | 65% |
| 剩余期限 | 30 天 |
| 年化无风险利率 | 4% |
| 股息率 | 0 |

| 方向 | 数量 | 合约 |
| --- | ---: | --- |
| 买入 | 1 张 | $135 Put |
| 卖出 | 2 张 | $125 Put |

初始入场价由上述参数下的模型价格确定，所以初始当日损益为零。期权合约乘数为 100，正股乘数为 1。

在默认仓位上加买 **2 张 $115 Put**，可抬升左侧尾部收益并形成左侧保护谷。此时右端仍是平台，尚未形成完整 W 型。

### W 型示例（以 SPCX 为例）

完整预设为：

```text
+1 × $135 Put
−2 × $125 Put
+2 × $115 Put
+1 × $135 Call
```

该组合的到期结构在 `$115` 和 `$135` 形成双谷，在 `$125` 形成中央尖峰。新增 Call 使右端随价格上涨而抬升，保护 Put 使左端随价格下跌而抬升。

点击 **W 型示例** 会新建仓位，并切换至 `S = $135、IV = 25%、T = 1 天、r = 4%`。按该预设的理论入场成本计算：

| 到期位置 | 组合损益，约 |
| --- | ---: |
| 左谷：$115 | −$140.95 |
| 中央尖峰：$125 | +$859.05 |
| 右谷：$135 | −$140.95 |
| 盈亏平衡点 | $113.59、$116.41、$133.59、$136.41 |

这些数值仅对应此预设。不同入场成本和既有移仓损益会改变曲线高度，W 型并不保证双谷微亏或中央盈利；左端收益也受标的价格不能低于零的约束。

**预设与叠加的区别：**“默认比率价差”和“W 型示例”仅重建当前标的的仓位、重置其已实现盈亏与交易记录，不影响其他标的；“叠加 W 左右翼”按当前理论价格补充保护腿及该标的预设的 Call（SPCX 为 $135），保留原仓位和既有盈亏。自定义仓位或移仓后的实际收益形状由全部持仓决定。以上操作均可撤销。

## 操作指南

### 调整情景与读取曲线

| 控件 | 范围 | 作用 |
| --- | --- | --- |
| 标的现价 S | 随标的配置变化，步长 $0.01 | 改变当前估值、Greeks、现价标记与预警状态 |
| 隐含波动率 IV | 15%–100%，步长 1 个百分点 | 改变当日理论损益曲线与 Greeks |
| 剩余天数 T | 1–60 天，步长 1 天 | 改变时间价值、当日理论损益曲线与 Greeks |
| 年化无风险利率 | −5%–30% | 在单腿计算器中编辑，作用于整个沙盘 |

绿色实线为**到期损益**，蓝色虚线为**当日动态损益**；竖向定位线标记当前现价，蓝点标记当前情景损益。

入场成本与持仓不变时，拖动 S、IV、T 不会改变到期折线。S 只改变曲线上的观察位置及对应指标；IV、T 改变当日估值曲线。滑块是独立的假设情景参数，不会自动推进真实交易时间。

“重置参数”恢复当前标的的默认沙盘参数，但保留现有仓位、入场成本和已实现盈亏。

### 编辑持仓

- 数量为正表示买入，为负表示卖出；期权按张、正股按股，数量必须为非零整数。
- 数字输入完成后按 Enter 或移开焦点生效。
- 修改类型、数量、行权价，会按当前理论价将原腿全部平仓，再建立修改后的新腿。
- 修改入场价是在修正历史成本基准，会直接改变损益；它不代表新成交。
- 点击行末的关闭按钮会平仓该腿，将其浮动损益转入已实现盈亏。
- 撤销持仓操作时，同时恢复该次操作前的仓位和操作时的沙盘参数；单独拖动滑块不生成撤销记录。

### 使用动态移仓助手

信号灯在现价**严格低于当前标的所有 Put 空头中的最高行权价**时变红。SPCX 默认触发价为 $125，TQQQ 为 $55；移仓或编辑仓位后，触发价随持仓更新。没有 Put 空头时不启用该预警。绿灯只表示没有触发这一条件。

| 操作 | 执行行为 |
| --- | --- |
| 追买保护 Put | 买入 2 张保护 Put；行权价为最高 Put 空头行权价减去当前标的间距，下限为 $0.01；无 Put 空头时使用该标的预设保护价 |
| Roll Down | 平仓最高行权价的一个 Put 空头持仓腿，按原数量卖出行权价降低的新 Put；降低幅度为当前标的间距的一半，按美分取整且至少为 $0.01，行权价下限为 $0.01 |
| 正股 Delta 对冲 | 新增 `−round(Net Delta)` 股；Delta 为正时卖空，为负时买入，使执行时残余 Delta 不超过 0.5 股 |

Roll Down **保持同一到期日**，当前版本不支持跨期展期。正股对冲不消除 Gamma，后续情景变化可能使 Delta 再次偏离零。保护腿买入后可通过持仓构建器中的“平仓保护腿”退出。

## 定价与记账口径

组合总损益使用统一公式：

```text
总损益 = 已实现盈亏
       + Σ [持仓数量 × 合约乘数 × (当前价值 − 入场价)]
```

当日价值使用 Black–Scholes 理论价格；到期价值使用期权内在价值；正股价值始终使用标的价格。模拟交易以当前模型价格执行，因此单纯开仓、平仓或平旧开新不会在执行瞬间凭空创造收益。平仓产生的损益继续计入之后的所有组合曲线。

| 指标 | 组合显示单位 |
| --- | --- |
| Net Delta | 等效持股数，股 |
| Net Gamma | 标的每上涨 $1 的 Delta 变化，股 / $1 |
| Theta | 时间经过一个自然日的理论价值变化，美元 / 天 |
| Vega | IV 每增加 1 个百分点的理论价值变化，美元 / 1% IV |

单腿计算器的价格和 Greeks 按每股计，组合统计再乘以持仓数量及合约乘数。

模型采用欧式行权、连续复利、365 天年基准；每个标的工作区内的所有期权共用到期日和 IV，股息率固定为零。不模拟波动率曲面、美式提前行权、手续费、滑点、流动性、保证金、借券费或资金账户利息。损益曲线用于理解假设情景，不是可成交报价。

## 技术与代码结构

```text
ThetaTree/
├── index.html    # 样式、定价引擎、React 界面与 Chart.js 图表
└── README.md     # 使用与开发说明
```

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Tailwind CSS | 3.4.17 | 浏览器端样式工具 |
| React / ReactDOM | 18.3.1 | 界面与状态管理 |
| Babel Standalone | 7.26.9 | 浏览器端 JSX 转译 |
| Chart.js | 4.4.8 | 损益曲线，使用 `update('none')` 关闭过渡动画 |

`index.html` 中的 `pricing-engine` 脚本独立于 React，包含正态分布函数、期权价格与 Greeks、组合估值、到期分段分析和交易记账。后续 JSX 脚本负责页面交互与图表。曲线采样额外包含精确行权价，避免采样间隔抹平到期拐点；页面展示当前计算与绘图更新时间，实际性能取决于设备和仓位数量。

可在浏览器控制台通过 `window.ThetaEngine` 调用计算函数。例如：

```javascript
// 参数顺序：类型、现价、行权价、期限（年）、IV、年利率、股息率。
// IV、利率和股息率使用小数；页面输入中的百分数会先转换。
const result = window.ThetaEngine.blackScholes(
  'call', 100, 100, 1, 0.2, 0.05, 0
);
console.log(result);
// price ≈ 10.450584，另含 delta、gamma、theta、vega。
```

多标的配置与工作区使用 `thetatree.multi-asset.v1` 本地存储键保存，恢复时校验数据结构及数值范围，并避免新建持仓 ID 与旧持仓冲突。撤销历史仅在内存中保留。当前没有导入导出、行情订阅或订单接口。

## 手动验收

1. 选择 SPCX 并载入“默认比率价差”，确认两条 Put 持仓、现价 $135、IV 65%、剩余 30 天及当日损益 $0。
2. 将现价调至 $124，确认信号灯变红；买入保护腿后，持仓增加且执行瞬间总损益保持连续。
3. 在默认比率价差下执行 Roll Down，确认 $125 Put 空头改为 $120 Put，平仓损益保留。
4. 执行正股对冲，确认新增正股腿，Net Delta 绝对值不超过 0.5 股。
5. 载入 W 型示例，确认四条腿、双谷与中心尖峰，以及约 $113.59、$116.41、$133.59、$136.41 的盈亏平衡点。
6. 改变 IV 和 T，确认当日曲线变化而到期折线保持不变；测试编辑、平仓和撤销。
7. 切换 TQQQ，确认默认行权价为 $60 / $55，保护腿为 $50，Roll Down 将 $55 空头移至 $52.50；再切回 SPCX，确认原有状态保留。
8. 新增 `TEST`（价格 $10、IV 40%、间距 $1），确认默认行权价 $10 / $9、滑块 $6.50–$13.50。修改持仓后刷新，确认标的、持仓与情景恢复；尝试重复代码或过大的间距，确认表单拒绝创建。

## 常见问题

**页面停留在加载状态或提示 CDN 依赖加载失败？**

检查 JavaScript 是否启用，以及两个 CDN 域名是否可访问。可尝试通过上述本地 HTTP 服务器打开，并在浏览器开发者工具的 Network / Console 中检查失败请求。

**为什么加了保护腿，谷底亏损反而变大？**

保护腿需要支付权利金。它可以改善极端下跌时的收益，但新增成本会压低其他价格区间的损益。完整 W 型还需右侧 Call，其成本也会计入曲线。

**为什么滑动参数后，点击重置参数没有恢复最初的仓位？**

参数重置只改变估值情景。要重建初始仓位，请使用“默认比率价差”预设；要回退一次持仓操作，请使用“撤销”。
